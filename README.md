# Student Course Management System

## Project Description

This project is a Student Course Management System developed using Spring Boot, JSP, and MySQL. It allows users to manage students and courses efficiently through a web interface.

## Features

- Add new students
- View list of students
- Search students
- View available courses
- Generate reports
- Manage student-course relationships
- Delete student records

## Technologies Used

- Java
- Spring Boot
- Spring Data JPA
- JSP (Java Server Pages)
- JSTL
- MySQL
- Maven
- GitHub

## Database

MySQL database is used to store student and course data. JPA is used to create and manage tables automatically.

## Project Structure

The project follows MVC architecture:

- Controller Layer — Handles user requests
- Service Layer — Contains business logic
- Repository Layer — Handles database operations
- Entity Layer — Represents database tables
- JSP — User interface
